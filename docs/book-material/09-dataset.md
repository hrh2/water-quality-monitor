# Chapter 9: Dataset

The training dataset is entirely synthetic, generated by
`ml/data_generation/generate_dataset.py` and documented in full
(generation methodology, class thresholds, and why the design avoids a
trivially separable problem) in
`docs/machine-learning/target-methodology.md`. This chapter's fuller
version should walk through that methodology narratively; it is not
repeated here beyond the summary below.

6000 rows are generated with class weights favoring `Safe` (45%) over
progressively rarer `Moderate` (30%), `Unsafe` (18%), and `Critical` (7%)
water, reflecting an assumption about what a real deployment would mostly
see. Each row's label is computed from a composite penalty score across
pH, turbidity, and TDS bands (informed by WHO/EPA reference values, used
as reasonable engineering reference points, not as a certification claim)
applied to a "true" generated value; independent Gaussian sensor noise is
then added on top to produce the "observed" value actually stored in the
dataset - meaning the classifier must learn from noisy evidence rather
than trivially inverting a deterministic rule. The real, observed class
distribution and summary statistics (not estimated - read directly from
`experiments/dataset_analysis/dataset_summary.json`) are covered in
`docs/experiments/summary.md`.
